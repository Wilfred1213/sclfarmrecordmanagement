# SCL Farm Record Management System

A centralized, enterprise-grade agricultural operations and resource planning platform built with Django. This system unifies disparate farm workflows—from intensive greenhouse crop tracking and livestock management to real-time inventory control and workforce health metrics—into a single, high-visibility workspace.

## 🚀 Core Functional Modules

*   **Operations Core (Dashboard):** A unified telemetry cockpit providing real-time operational oversight across all functional areas.
*   **Greenhouse Matrix (`greenhouse`):** Manages precision crop production cycles, nursery schedules, transplant records, harvesting metrics, and intensive layout workflows.
*   **Livestock Hub (`livestock`):** Tracks animal batches, nutritional programs, health records, and productivity logs.
*   **Inventory Control (`inventory`):** Provides real-time stock balance tracking, asset allocation for returnable tools, consumables auditing, and historical transaction logging.
*   **Staff Health Portal (`medical`):** Centralizes workplace incident logging, safety compliance, treatment profiles, and employee wellness reporting.

## 🛠️ Tech Stack & Architecture

*   **Backend Framework:** Python 3.11+ / Django 4.2+ (MVT Architecture)
*   **Frontend Interface:** Semantic HTML5, CSS3, Bootstrap 5, FontAwesome 6
*   **Dynamic UI Enhancements:** HTMX (for asynchronous form processing and reactive states)
*   **Database:** SQLite (Development Default) / PostgreSQL ready
